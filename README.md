# HireSense

AI-Powered Recruitment & University Placement Intelligence Platform

## Status

🚧 Under Development

## Overview

HireSense is an AI-powered recruitment and placement intelligence platform designed to help candidates, recruiters, and university placement administrators make better data-driven decisions.

## Planned Technology Stack

- Python
- FastAPI
- React
- MySQL
- Pandas
- NumPy
- Scikit-learn
- NLP
- Plotly
- Docker

## Core Capabilities

- Resume parsing
- Skill extraction
- Job description analysis
- Candidate-job matching
- Candidate ranking
- Skill-gap analysis
- Recruitment analytics
- Placement analytics
